How the VAT column is computed

  • Buyer in NL: 21% VAT (Dutch domestic rate, on digital services).
  • Buyer in another EU country: the local rate applies under the OSS scheme (e.g. 19% in DE, 20% in FR).
  • Buyer outside the EU: 0% (export of services).
  • Buyer country unknown: shown as UNKNOWN with 0% — the accountant decides.

VAT is computed as VAT-inclusive: vat = net × rate / (100 + rate). We assume B2C consumers; if you start invoicing EU businesses with VAT numbers (reverse charge), tell me and we'll add that flag.

This is a data-export tool, not tax-compliance software. Final filing should be done by a qualified Dutch accountant using this CSV as input.
